# القائد الآلي — NMK Ai | محاكاة GTA V

<div dir="rtl">

## ما هو المشروع؟

**القائد الآلي (NMK Ai)** — نظام محاكاة قيادة ذاتية يعمل داخل لعبة
Grand Theft Auto V، يتيح تجربة منظومة قيادة كاملة (كاميرا، توجيه، تحكم
بالسرعة، رادار، نموذج قيادة) في بيئة افتراضية آمنة وقابلة للتكرار.

## المزايا

- **واجهة عربية كاملة** بهوية NMK Ai — لوحة تحكم القيادة، الواجهة المباشرة، وكل النصوص.
- **تحكم بيد Xbox**: 
  - ⬆️ السهم العلوي: زيادة السرعة
  - ⬇️ السهم السفلي: تخفيض السرعة
  - 🅰 A: تفعيل القائد الآلي
  - 🅱 B: مفتاح التوجيه الرئيسي
  - ❌ X: إلغاء التثبيت | ⭕ Y: الكاميرا | START: إيقاف كلي
- **مستشعرات محاكاة**: كاميرا أمامية، رادار مركبات مع قياس المسافة والسرعة النسبية.
- **أتمتة كاملة**: إقلاع المنظومة، إحضار مركبة التجارب، التفعيل، والتحقق بالقياس المباشر.
- **دعم دقات عرض مرنة** مع تحجيم تناسقي يحفظ هندسة الكاميرا.

## البنية

```
GTA V Enhanced (محول المركبة والقياس)
        ↕ بيانات حية (تلكيمتري/إطارات)
مضيف الالتقاط (ويندوز) — تحجيم ومعالجة الكاميرا الرقمية
        ↕
الجسر الداخلي (بيئة لينكس معزولة) ←→ منظومة القائد الآلي NMK Ai
        ↑
لوحة التحكم + الواجهة المباشرة + وحدة يد Xbox
```

## التشغيل السريع

1. شغّل `Start-NMKAi.cmd` (يقوم بإقلاع المنظومة كاملة وتشغيل اللعبة).
2. من داخل اللعبة: ادخل وضع القصة واستخدم لوحة التحكم أو يد Xbox.
3. للإيقاف: `Stop-NMKAi.cmd`.
