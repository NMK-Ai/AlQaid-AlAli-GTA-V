# UI feature audit

Pinned FrogPilot commit: `f8fb0668ed7fd13caf5a21e1ac27f6378df1b37f`.

This source inventory covers all FrogPilot settings panels, stock offroad panels, nested parameter references, and direct action controls. Rows marked as dependencies are not necessarily separate visible toggles. It does not claim that every UI item has been exercised or that every backend works on PC.

## Driving input audit

All four assignable wheel inputs are supplied: B tap, B long, B very long, and L. The six assignable functions also have direct keys: personality F4, coast F1, pause steering F2, pause gas/brake F3, Experimental F5, Traffic F11. Cruise master/Set/Resume/Cancel, +/- button events, both blinkers, and physical pedals/steering are supplied. See [controls](CONTROLS.md).

A visible Windows driving panel supplies all listed actions without stealing GTA focus. Onroad mouse actions were inspected in `frogpilot_buttons.cc`, `frogpilot_annotated_camera.cc`, and stock `buttons.cc`: personality, Experimental Mode, speed-limit confirmation, and Record have clickable buttons. Clicking the separate FrogPilot window now preserves automated driving; physical game input is sampled only while GTA is focused. Stale camera/control data still releases actuation. Settings and Back were visually verified after removing the launcher move that misaligned WSLg mouse coordinates.

Custom cruise intervals, hold intervals, offsets, reverse increase, Eco/Sport drive modes, and dedicated lane-change nudge buttons are connected. Automatic/nudgeless lane changes receive blinkers and GTA vehicle occupancy for blind spots. Unit checks cover cruise interval semantics; complete lane-change execution and every wheel-button assignment remain unverified.

Other implementation gaps: device screen recorder relies on Qualcomm Wayland/EGL buffers; video encoding is disabled. Genuine rlog capture was verified and is enabled on future launches. Alternate driving models need compatible CUDA compilation; game weather and posted-speed sources are absent; vehicle-specific actuator tuning is not fully propagated into the GTA profile. Device hardware and physical vehicle accessories have no matching hardware here. Real-world maps and driver monitoring are excluded by the user.
